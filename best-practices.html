Best Practices for Better Prompts

  • Be Specific: Provide as much context and detail as possible.
  • Define the Persona: Tell the AI who it should act as (e.g., "Act as a senior software engineer").
  • Use Delimiters: Use triple quotes or XML tags to separate instructions from content.
  • Specify Output Format: Clearly state if you want JSON, Markdown, or a table.
